# Controller Home — Gestão Patrimonial

Aplicação autónoma para gestão de imóveis, contratos, inquilinos, rendas, encargos, obrigações, manutenção, inventário e documentos.

## Tecnologia

- Next.js e React
- Firebase Authentication com conta Google
- Cloud Firestore para os dados patrimoniais
- Firebase Storage para novos documentos e imagens
- Publicação na Vercel

## Execução local

```bash
npm install
npm run dev
```

## Validação

```bash
npm run build
```

O projeto não depende do runtime, autenticação, D1 ou R2 do GPT Sites.
